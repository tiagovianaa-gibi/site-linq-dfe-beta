Servidor local necessário

O Chrome bloqueia o acesso a arquivos locais pelo protocolo file://, o que impede a geração do PNG. Para baixar, sirva o projeto via HTTP:

Opção 1 — VS Code Live Server
Instale a extensão Live Server no VS Code, clique com o botão direito no arquivo e escolha "Open with Live Server".

Opção 2 — Python (já instalado na maioria dos PCs)
No terminal, na raiz do projeto:

python -m http.server 8080

Depois abra: http://localhost:8080/dashboard/arriuna-card-generator.html

Opção 3 — Node.js

npx serve . -p 8080
